# Storage Estimator - Feature Version

## Purpose
This program converts a file size from MB to KB.

## How to Run
1. Open a terminal in this folder.
2. Run: python storage_estimator.py
3. Enter a file size in MB when asked.

## Example
Input: 2
Output: Size in KB: 2048.0 KB
